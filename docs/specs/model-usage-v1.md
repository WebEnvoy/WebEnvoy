# Model Usage V1：模型使用与可选网页辅助

状态：Proposed；版本：1.0；owner：Core（配置/用途/授权/调用协调/运行归因）、Harbor（浏览器现场/目标/控制/执行）、可信 owner 入口（用户决定）、Plugin（正式宿主投影）。产品归口：[#558](https://github.com/WebEnvoy/WebEnvoy/issues/558)；首个条件验证：[#559](https://github.com/WebEnvoy/WebEnvoy/issues/559)。

依据：[canonical](https://github.com/WebEnvoy/.github/blob/main/docs/product-architecture-v1.md)、[ADR 0013](../adr/0013-optional-model-assisted-browser-tasks.md)、[Plugin Exposure](plugin-runtime-exposure-v1.md)、[Capability Discovery](capability-discovery-v1.md)、[Observation Targets](observation-targets-v1.md)、[Grant](grant-wire-contract-v1.md)、[Browser Runtime](browser-runtime-capabilities-v1.md)。正式接受须先完成 canonical 对应修订；文档接受不表示模型已支持或功能已交付。S0 的 App 冻结不改变本规格的可选、有界、非 V1 阻塞边界；配置与停止由可信 owner 入口承接，不要求 App。

## 1. 用户结果与范围

用户配置自己批准使用的模型连接，按用途选择是否启用，在已批准的网页和操作范围内委托一段短任务；可以知道用过的模型、外发范围、可确认费用、已做动作、真实结果和待处理事项。关闭辅助后，原有 Agent/人类路径、长期 Profile 和历史结果保持可用。

本规格定义通用模型使用行为及首个可选网页辅助用途，不增加 V1 必须完成项，不建设通用聊天/自主 Agent/工作流平台。首个正式入口优先为现有 installed Plugin；未来用户直接发起不要求每步使用 Host Agent，但本轮不新增完整聊天入口。

## 2. 四个独立概念

| 概念 | 含义及边界 |
| --- | --- |
| Model Provider | 用户批准的模型接入服务，可为直连、Gateway 或未来本地服务；不是浏览器供应方。 |
| Model | 请求的具体模型与实际返回的可识别版本；别名不等于固定权重。 |
| Model Capability | 该模型实际提供的能力、限制和证据，例如原生 evaluation、有界选择、文本或视觉；缺证据不默认为支持。 |
| Model Usage | WebEnvoy 使用模型的目的、允许输入、候选、停止与结果规则；首个用途为有界网页辅助。 |

连接/凭据可复用不等于所有用途自动启用。新增用途不能扩大发送数据、权限或费用；新增模型必须满足该用途要求。不按用途建立多套 Provider，也不现在冻结全部持久对象、SDK类型或 wire 名称。

模型 evaluation 是根据状态作出判断，不是 Browser Runtime 的 Controlled evaluation（受控网页脚本执行）。两者不能共用能力标识或相互授予权限。

## 3. 配置、选择与用户可见事实

### 3.1 配置与启用分开

用户在“模型”管理连接，在“网页辅助”选择关闭或启用及首选模型。默认关闭。保存密钥、设置默认或测试连接，都不自动批准真实网页外发或任务执行。

连接测试只用合成内容；显示它检验的是认证/所需调用能力，不表示任意网页任务已通过。失败要区分未配置、认证失败、能力未提供、版本不匹配、服务/额度不可用；不能一律提示“请再试一次”。

凭据通过可信 owner 入口送到安全存储。普通 Agent 只取得非敏感连接引用和状态；密钥不得进入浏览器、Plugin 配置副本、源码、普通日志、Run 正文或诊断。设置与运行读取同一 owner，不随 App 退出丢失。

### 3.2 实际选择

在用户已启用且主体获准的前提下，本次显式选择优先用户默认；没有可用选择则报告，不能暗用产品推荐。模型选择不改变 Browser Provider、Profile 身份或账号归属。

一次辅助任务固定本次请求模型、连接及批准的路由边界；用户修改默认只影响后续任务。取消/撤销仍立即阻止后续派发，不因“冻结选择”而忽略。需要改模型时先结束当前辅助段，显式记录接续，不在未知写入后以换模型重试。

记录请求模型名、实际返回模型/版本和可取得的实际路由。供应方未提供的版本或费用应标未知；不能把 latest 别名冒称精确版本，也不能把调用方取消冒称供应方未计费。

### 3.3 Gateway 与自动路由

用户批准的是连接和实际接收范围，不仅一个显示名称。Gateway 的转发、备用模型、备用推理服务及留存说明都受相同外发规则约束；目录中可见不表示 WebEnvoy 已验证。

首个候选固定 Jev 路线，不静默替换成普通聊天模型。不在首版建设自动选厂商平台。未来自动路由必须由用户明确启用，候选均满足用途资格及外发范围，且实际使用可回读。

## 4. 使用权限、外发与费用

网页访问/操作权限、使用某个模型/用途的权限、向实际接收方发送指定数据的同意是不同决定。统一在现有 Core/owner 授权链落实，不复制权限系统，也不让模型/SDK/Plugin 签发授权。

首个用途只发送必要的有界结构化页面状态、允许的目标说明、目标与少量相关历史。默认不发送截图；不得发送密码、验证码、Cookie、token、原始 Profile、私有端点、未获准网页、文件正文或无关账号数据。获准普通表单文本仍须按最小范围和脱敏规则处理，不因“非密码”自动视为可发送。

页面内容一直是不可信数据，不得改写目标、扩大候选、改变接收方、调整授权或取消安全检查。脱敏先于外发、日志和持久化；SDK 的调试、trace 或 Gateway 日志不得成为旁路。

开始前明确动作/请求/时间/费用边界；超过边界停止新的模型请求和网页派发，并报告已发生事实。费用无法实时精确确认时，说明能力边界，至少有获准的请求/时间限额；不把估算当账单或承诺不可实现的硬金额上限。扩大费用或数据范围需 owner 决定。

## 5. 有界网页循环

### 5.1 开始条件

必须有明确目标、Profile/原 Instance/任务 Page、所需已支持操作、必要输入、停止条件、主体和有效授权，以及批准的模型连接/用途/外发范围。准备候选复用 #539/#540 和后续 [#555](https://github.com/WebEnvoy/WebEnvoy/issues/555) 的交付，不复制静态能力表或控件规则。

检查可客观证明的条件：目标可信、相关状态足够、候选与请求未超限、权限/控制有效、模型满足用途。完整性针对当前声明的观察范围和任务必要信息，不要求全网站所有内容均已遍历；必要内容缺失时补有界观察或停止，不能截断候选后假称足够。

不宣称程序可以确定判断所有任务是否“简单”。复杂目标的分解可以来自真实 Host Agent/用户；不为准入再建设开放式业务规划器。

### 5.2 选择、执行与重观察

模型可以连续选择已有操作、目标及 DONE/BLOCKED；不要求逐步返回 Host Agent。只有当前正式支持、被暴露、获准且目标适用的操作才可进入当前执行候选；状态说明不是持续授权。

operation 与 target 可以在一次原生 evaluation 中共同提出；只消费所选 operation 对应的合法 target。所有返回均须校验形状、候选成员关系、作用域及观察绑定；未选择分支不得派发，畸形/候选外结果不得被猜测修补。

执行使用原可信 target ref，重新检查授权、Page/document、目标身份/状态、ControlLease 和 Browser Provider 准备状态。不能通过 selector、坐标、名称重找或任意脚本旁路。动作后按原合同重新观察，不跨批次拼接现场。

首个验证使用明确给定文本；允许未来另选获准文本模型，但文字生成不是 Jev 的有界选择能力，也不能借模型辅助默认发送更多页面内容。

### 5.3 confidence 与限制

confidence/probabilities 只是供应方返回的判断信息，不能成为授权或独立成功证据，也不能跨不同模型当成同一量尺。用于退出辅助的阈值必须先有具体用途的校准证据；没有时如实缺失，不设想当然的统一数字。

已证明的缺能力、缺输入、无可信候选、预算触达、无进展及模型错误可以终止本段；不能只因模型返回高 confidence 就越过必要检查。

## 6. DONE、BLOCKED 与结果核验

DONE 表示模型认为无需再操作。随后使用该任务实际具备的独立结果证据；通过才确认对应业务结果。普通操作成功、页面提示、截图或另一模型同意，都不自动替代业务核验。没有可用核验方法时明确结果未确认，不能假设存在万能 Verifier。

BLOCKED 表示当前辅助路径不能推进，不等于整个任务失败。保留原因、已做动作、原 Run/receipt、结果和待处理事项；按用户选择交回真实宿主或等待人处理。

核验失败不自动再提交：先区分明确未发生、已发生但不符预期和无法确认。任何后续动作都须有新鲜现场与授权；已派发且未知的原写入只查询/对账/人工处理，不能因新观察、模型 DONE 或核验失败而换 key 重放。

## 7. 停止、接管与交回

停止辅助、撤权、连接失效和人工接管必须按原规则阻止新派发，并尽可能取消在途模型请求。取消不保证供应方未处理或未计费；迟到回复不得复活循环。已派发外部效果不倒写为未派发。

模型不得夺回控制权；明确交还后重新观察原任务页。模型失败或退出不终止无关 Profile，不删除历史结果；关闭辅助不停止原浏览器，用户另行停止 Instance 仍走原生命周期操作。

“回到当前 Agent”只表示将交接结果投影给实际发起任务的宿主，并由其沿正式入口继续。宿主缺席或用户直接发起时进入待处理，不能暗中启动另一个大模型。接续必须引用已做动作与原结果，不能重新从任务第一步运行。

模型 API 的有限重试可能产生额外费用，但不必然产生浏览器动作；模型重试和网页写入重试分开记录。任何传输重试、SDK resume 或 Gateway fallback 都不得重复派发已经消费的决定。缺乏在途结果证据时暂停查询/对账，不用更换 idempotency key 消除未知。

## 8. 记录、安装与资格

复用现有 Run/operation/receipt 和活动摘要，保留本次用途、模型请求/实际版本、已知路由、调用时间、usage/已知或估算费用、退出原因、原动作结果和核验结论；模型调用记录不取代外部结果。默认不长期保存完整表单或原始 prompt/response，仅保留核验/诊断确有必要且获准的有界材料。

用户必须区分未配置、已连接、能力未提供、未获准、待处理和本用途已验证；SDK/上游宣称支持、测试请求成功、installed 客户端与真实 Agent 的证据分别表达。

第三方 SDK 类型不直接进入公共持久合同。正式接入需固定 package/model 来源及安装配对，同步 strict reader、schema、正反 fixture 和版本兼容；这些文件实际形成后再由 contracts 索引，不在本 spec PR 创建空路径。旧安装不理解辅助能力时局部拒绝，仍可使用原有浏览器与管理能力。

## 9. 首个验收与后续扩展

#559 的首次场景为无账号受控表单、只改指定字段、获准保存与独立回读，输入明确给定。最低证明如下：

| 结果 | 必须证明 |
| --- | --- |
| 原路径保持 | 关闭/未配置辅助时原 Agent/人类操作、Profile 与历史结果不受影响。 |
| 配置与外发 | 合成连接测试；密钥不泄漏；网页权不自动授予外发；未获准接收方/内容不发送。 |
| 连续任务 | 模型连续执行已有动作并可 DONE/BLOCKED，不要求每步调用 Host Agent；只改指定内容。 |
| 错误与现场变化 | 候选外/格式错误/旧目标/状态变化准确拒绝；接管、停止和迟到回复不造成输入。 |
| 真实结果 | 假 DONE 不变成成功；无核验保留未知；BLOCKED/宿主缺席明确待处理。 |
| 不重放 | 丢失一次写响应，查原 Run/receipt，模型重试、换模型或宿主接续不重复写。 |
| 收益证据 | 相同基线/目标/初态/核验，保留全部尝试；总时间/费用包含观察、等待、核验、失败和接续。 |

验证结论可以采用、限定范围采用或暂缓，不冒充正式功能交付。正式产品化还需配置/关闭、安装、真实宿主及恢复证据；spec 接受或验证关闭不关闭 #558。

新增用途复用模型连接，新增模型复用用途要求，但都需独立证明实际能力与数据边界。未来可能用途不在本规格预建任务/工具；用户权限、账号正式归属、发布/删除许可和 unknown 重放不是模型可决定事项。

## 10. Design Obligation 与非目标

本文件固定行为语义；不冻结 SDK 函数、完整字段/数据库表或新的权限枚举。实现前：

- DO-PLUGIN-EXPOSURE：正式模型能力发现、任务委托/查询/退出或新的投影形成时 triggered，同步 Plugin Exposure 与实际 schema/兼容。
- DO-GRANT-WIRE：新增可委托模型使用、外发或持久跨进程授权字段时 triggered；复用现有权限体系不等于无需更新合同，不能继承 #555 的 not-triggered。
- DO-APP-IA：完整“模型”设置、导航或活动工作台发生变化时 triggered；最低 owner 配置/外发/费用确认无论是否触发完整 IA 都须定义并验收。
- Browser/Network/Console/Provider-private-schema：默认不改变相应能力或持久配置；实际改变时重新判断，不把模型 HTTP 请求混入网页 Network 权限。

不新增强制模型依赖、第二套 Runtime/授权/Run/恢复系统、模型市场、通用聊天/自主 Agent/DAG 平台、长期私有 SDK/bridge、任意脚本或新 Browser Provider。#555/#556 与 #557 原范围保持；本方向非 V1 当前完成门，但可选功能一旦交付不豁免公共质量要求。
